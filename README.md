A clean implementation of the decompressing algorithm used by NFL 07 game. This clean room implementation has been created through ea_madden.c decoder written by Aluigi with the help of an AI agent. All call functions generated by AI were converted into macros by me. The goal is not only an functional decoder, but a highly sophisticated decoder and without the extra overhead during the call functions, to try to bring this implementation closer to the original decoder written at the time of the game's release. This C code is able to extract and decompress the TERF files used by NFL games, just like the ea_madden_terf.bms script. The decompression routine contains 2 paths: the mode 0 (currently implemented and functional) and the mode 1 (still is not implemented). I've tested with more of 100 files and all these files uses the mode 0. The mode 1 starts at offset 0x758E7B at EA_Madden_dump[] binary that is in ea_madden.c written by Aluigi. The EA_Madden compression uses Huffman encoding + LZ to achieve a good compression ratio.

EA Madden compression specifications:
- 0x00..0x0FF are literal bytes
- 0x101..0x11C are LZ length symbols
- The dictionary is a 0x8000-byte circular window
- The symbol 0x100 it is the end of the current compressed block
- each compressed block starts with a 1-bit block mode
- mode 0 contains 285 + 30 four-bit Huffman code lengths
- There is a main Huff tree and another Huff tree to represent the distance symbols
